# MedVideoAI

Native Android starter project for an AI Medical Video Generator, built with Kotlin and Jetpack Compose.

## Starter features
- Medical topic input and quick topic presets
- Tamil, English, or bilingual selection
- Video duration and visual style selection
- Prepare a video request from the selected options

## Important
This starter currently provides the Android interface only. Real AI video generation requires a secure backend and an AI video/narration provider. Do not put private API keys inside the Android app.

## Android build
Open this repository as a Gradle project in Android Studio or a compatible Android IDE. Use JDK 17 and Android SDK 35, then sync Gradle and run the `app` configuration.

Package: `com.example.medvideoai`
